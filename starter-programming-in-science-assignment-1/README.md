# Programming in Science - Assignment 1

This template repository is the starter project for Programming in Science Assignment 1. Written in Python, and tested with Pytest. For this assignment skip Pytest.

#### Writing code is not the only goal. Professional programmers spend significant time reading, analyzing, improving, and explaining existing code.

1. Your task is to deepen your understanding of programming concepts and design decisions.

2. You may use tools such as ChatGPT, Copilot, or other AI assistants as learning partners.

3. You must demonstrate your understanding, not copy AI responses.

4. Every answer must include:
      - your explanation in your own words,
      - evidence of experimentation or modification
      - submit your responses in the one .py file, use comments (`#`) to describe your answer in between your python code.
        
### Tasks (Complete for EACH Question)
   
    1. Code: add main funtion block at the end of each question which uses all functions as provided by teacher solution
    
    2. Understanding: identify: inputs, outputs, main variables, functions used
    
    3. Modification: modify the solution and explain in comments in any (choose one, not all) meaningful way, such as:

      - change input conditions

      - add validation

      - alter calculation logic
         
      - improve output formatting

      - add a new feature

### Question(s)

Q1. **(25%)** Conditional Statements – The ```If``` Statement:

   - Write a function that checks if a number is positive, negative, or zero and returns a corresponding message.

Q2. **(25%)** For Loop – Making a Star Shape:

   - Write a function that prints a star shape with a given number of rows using a ```for``` loop. For example, if the input is 5, the output should look like this:

   ```
   *
   **
   ***
   ****
   *****
   ```

Q3. **(25%)** While Loop – Counting Multiples of 3:

   - Write a function that counts from 1 to ```limit``` using a ```while``` loop. For every number that is a multiple of 3, the function should return "Multiple of 3" instead of the number.

Q4. **(25%)** Sum of Even Numbers in a Range:

   - Write a function that takes a start and an end value and calculates the sum of all even numbers within that range.
